# SII FAQ: ¿se puede cambiar el estado de una factura electrónica ya reclamada?

| Tema | | | | |
| Factura Electrónica \| Conozca sobre Factura Electrónica \| Aspectos Generales \| Definiciones \| Factura Electrónica \| Errores y Rechazos | | | | |
| Pregunta | ID: 001.003.6295.004 | | Fecha de Creación: 30/08/2012 | |
| ¿Si reclamo una Factura Electrónica de un proveedor, puedo posteriormente cambiar el estado a otro? | | | | |
| Respuesta | | | Fecha de Actualización: 21/02/2023 | |
| No, en el caso que se hubiere reclamado una Factura Electrónica de un proveedor, posteriormente no se puede cambiar de estado a Aceptada y dar el Acuse de Recibo de la Factura Electrónica. Si bien su sistema de facturación electrónica podría permitirlo, legalmente ya fue reclamada la factura por lo que no tiene derecho a crédito fiscal, y por lo tanto el Registro de Aceptación o Reclamos de un DTE que se encuentra disponible en el SII solo considera la primera acción que sea realizada por el receptor de la factura electrónica. | | | | |
