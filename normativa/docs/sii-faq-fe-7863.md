# SII FAQ: qué información de boletas electrónicas se registra en el Registro de Compras y Ventas

| Tema | | | | |
| Factura Electrónica \| Boleta electrónica de ventas y servicios \| Comprobante de pago electrónico | | | | |
| Pregunta | ID: 001.003.7863.005 | | Fecha de Creación: 02/03/2021 | |
| ¿Qué información debo registrar en mi Registro de Compras y Ventas? | | | | |
| Respuesta | | | Fecha de Actualización: 27/04/2023 | |
| La información de sus ventas con boletas de ventas y servicios electrónicas es cargada de forma automática en el Registro de Compras y Ventas con la información del Resumen de Ventas Diarias que se envía también diariamente desde su sistema de emisión de boletas electrónicas. En el caso de sus ventas a través de medios de pago electrónicos, de igual manera a como se realizaba cuando el comprobante de pago electrónico reemplazaba a las boletas en papel, debe revisar en el Registro de Compras y Ventas disponible en nuestro sitio web, que las mismas se encuentren cargadas. De no ser así, deberá complementar el Registro de Compras y Ventas con la información de sus ventas pagadas con medios de pagos electrónicos, diferenciando las ventas afectas de las exentas. Este complemento debe realizarlo de forma previa a su declaración mensual de F29. Puede obtener mayor información relativa a este tema en el sitio web del SII, Menú Normativa y Legislación, Resoluciones, opción Resolución SII Ex. N° 176, del 2020, complementada con Resolución SII Ex. N° 76 de 2021. | | | | |
